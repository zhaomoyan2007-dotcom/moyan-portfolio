# 墨岩 · Photography & Cinematography

原生 HTML/CSS/JS 摄影与短片作品网站。Decap 管理中英文内容，GitHub 保存工程和内容，Vercel 构建发布，Cloudinary 保存线上网页图片。

## 本机运行

需要 Node.js 22 或更新版本：

```sh
npm ci
npm run dev
```

- 网站：<http://localhost:4319/>
- 管理后台：<http://localhost:4319/admin/>
- 本地保存直接修改本机文件，不会上传公网；线上草稿审核流程需在线上后台使用。
- 网站和内容代理只绑定 127.0.0.1；4319 或 8081 被占用时拒绝启动，避免编辑错误工程。
- 布局试版先在本地验收，确认后统一发布。原片、凭据和私密资料不放进公开仓库。

## 后台按页面顺序编辑

“01 · 首页与关于”中的字段按照官网从上到下排列：

1. 开场：署名、背景图、署名下的身份文字。
2. 首页自我介绍：中英文独立，空一行分段。
3. 剧场入口：双按钮下方的独立背景图。
4. 短片创作栏目简介：具体影片在作品项目中维护。
5. 关于我：主副标题、自由介绍文本 → 创作方向与实践 → 远期目标 → 与我合作 → 联系方式。

简介段落与栏目条目可增删、拖动排序；空条目不展示。自由介绍文本支持 `**文字**` 自定义加粗，仅渲染安全行内重点，不执行 HTML。实践条目可关联公开作品；联系方式可填账号及可选 HTTPS、mailto、tel 链接。旧版未分类精选、旧简介与旧联系方式已隐藏，历史值仍兼容保留。

右侧提供开场、剧场、短片简介、关于与合作的双语内容预览；顶部区域按钮可快速定位。它用于检查内容，完整视觉以左侧“查看网站”打开的本地网页为准。短片预览复用官网影片样式，避免列数与文字标签漂移。

## 添加与维护作品

进入“02 · 摄影与短片项目”。筛选菜单按官网顺序提供纪实、当代与情绪、人像、体育、航拍、自然风光、短片创作，也可筛选公开／隐藏；排序菜单可按排列数字、短片时间或中文标题查看。

表单先选栏目、填名称，再维护影像、文字、展示选项。类别切换只影响编辑控件的显隐，不删除历史值：

- 摄影：项目照片至少一张，开启“加入首页照片流”才进入首页精选；人像额外选择环境或棚拍。
- 短片：独立首图 → 其余切片 → 参与职责 → 创作阐述。无需开启摄影精选；公开短片自动进入首页。日期填 `2026`、`2026-09` 或 `2026-09-01`，由新到旧排列；旧项目未填日期时沿用原年份。
- 摄影按排列数字由小到大；短片仅在日期相同时以此排序。
- 简短介绍用于全部作品目录和详情，不会添加到首页摄影照片流。
- 固定地址创建时自动生成并锁定，修改名称不改地址。
- 短片不显示人像子类与摄影精选；摄影不显示短片时间和职责；已有旧年份会保留。旧体育分组兼容保留，但不影响布局。

首页摄影中，纪实、当代与情绪、体育每项目一排横向照片流，不显示项目介绍；人像按环境／棚拍组织。航拍和自然风光为紧凑三列原比例网格，小屏两列。短片为较大首图与三列静态切片。图片上传顺序就是图组顺序。

## 保存与上线

“官网可见性”与顶部工作流状态是两件事：

1. 选择“公开展示”或“隐藏”。
2. 线上先保存工作流草稿并预览，再从顶部发布，合并正式分支。
3. 等待 Vercel 构建成功，再检查正式网站。保存成功不等于部署成功。

`cms/` 草稿分支不生成公开预览；后台内部预览可用。公开仓库中的分支仍可能被读取，不应存放保密内容。撤下项目不会自动删除 Cloudinary 图片。

账户、授权、域名和服务器变量说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。本次工程整理未变更真实账户配置，云端登录、上传和工作流发布需要发布新工程后单独回归。

## 图片上传

线上使用“选择照片并自动压缩”生成网页副本：最长边 3000 像素、不放大、WebP、目标 4MB 内，保留透明背景，移除拍摄与定位信息；电脑原文件不变。支持静态 JPEG/PNG/WebP，原文件上限 100MB、2亿像素、单边 30000 像素，批量逐张处理并支持重试。浏览器无法安全缩小解码时明确报错。

“从 Cloudinary 图片库选择”用于复用已上传的图片。图片库原生 Upload 不经过压缩；本地图库用于本机开发，不能代替真实云端上传验收。网页副本不能代替原片备份。

## 工程边界与检查

- `content/site.json`：网站资料；`content/projects/*.json`：项目。
- `public/`：网页与后台；`public/media.mjs`：浏览器和服务端共享的纯媒体助手。
- `lib/`：内容校验、CMS 配置、登录与上传授权；不会整体复制到浏览器。
- `scripts/`：构建、本地服务与检查；`api/`：线上服务端接口；`tests/`：回归测试。
- 现有集合名称、文件路径和固定项目地址保持兼容。未经明确迁移，不更名或删除历史内容字段。
- 密钥仅存服务端环境变量。公开仓库默认 OAuth 范围为 `public_repo`；显式配置 `repo` 仍兼容，详见部署说明。

```sh
npm test
npm run check
npm run build
npm run check:deploy
```

构建输出 `dist/`，只导出公开项目。内容校验失败时停止构建；不会把原始内容目录、测试、本地上传接口和环境变量打包上线。Decap 固定为 3.17.1，首次从 npm 获取精确版本并校验 SHA-512；vendor、dist、缓存及 node_modules 不提交。升级 Decap 时需回归类别控件显隐与预览，许可证见 [THIRD_PARTY.md](THIRD_PARTY.md)。
