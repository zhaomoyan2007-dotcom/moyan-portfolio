- 首页字段与网页顺序不一致，“关于”中远期目标、合作和联系方式交错：按实际阅读顺序重排，栏目编号和用途标注更清楚。

- “公开状态”和顶部“发布”容易混淆：前者改称“官网可见性”，明确区分展示开关与工作流发布。
- 首页资料只预览关于、短片预览仍为两列且保留旧标签：首页预览加入开场、入口和短片简介；影片预览复用官网 films.css 的三列结构，移除前台已删除的标签。所有摄影类别统一使用分类照片预览。
- 预览定位与关联作品入口：区域按钮在预览文档内滚动；关联作品打开真实网站详情，不在预览框内重载后台。
- 浏览器 media.mjs 原先由整个服务端 content.mjs 复制生成：只保留五个共享媒体助手，从 6557 字节减至 1728 字节；服务端继续通过原导出名使用同一实现。此项属于减少无用代码，并非发现密钥泄露。
- OAuth 未配置范围时原先默认为 repo：改为 public_repo；显式 repo 配置兼容保留。没有更改真实账号或环境变量。
- README 含过时的本地待发布状态、旧首图尺寸和旧联系方式编辑说明：合并为当前操作手册。
