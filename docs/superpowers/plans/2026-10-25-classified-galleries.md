# 分类照片流

确认范围：精选照片区域六类：纪实、当代与情绪、人像（环境/棚拍）、体育（固定3张篮球、可滑动3张足球）、航拍、自然风光。纪实/当代按项目纵向分排，每排独立横向滑动；不显示项目名或简介。人像横向，航拍/风光双列。点击放大，组内键盘/按钮/触屏切换。用户明确撤下现有8张精选，仅制作空栏目，不删除云图片或更改首图。

1. 先测试分类/子类/展示方式/体育数量边界及草稿隔离，再扩充内容模型与CMS字段。复用项目记录，首页不复制另一份图序。
2. 新增gallery组件：独立横向滚动及箭头状态，保持图像比例；足球始终有横向溢出；篮球固定三列；双列窄屏一列。
3. 首页渲染全部空栏目，纪实/当代预留两排、子类分别一排，其余双列。保留栏目标题，无项目介绍。已发布featured项目填充对应位置。
4. 独立photo dialog负责组内导航、Escape、焦点返回、左右键及滑动，避免与项目路由dialog冲突。
5. 更新导航/全部作品分类/CMS提示；清空homePhotos但不删除库文件。
6. 测试、check、build；本地临时测试数据覆盖有图交互后恢复空内容；代码审查，上传并验证正式地址。

验收记录：28项测试/check/build通过；临时本地项目验证两排独立滚动、足球3张仍有溢出、篮球3张固定、方向键灯箱切换、Esc焦点返回、390px无页面横向溢出及双列变单列。临时项目已移除，正式构建应为0项目、0精选照片。触屏切换逻辑已实现，实际手机手势仍可在正式素材加入后复核。
